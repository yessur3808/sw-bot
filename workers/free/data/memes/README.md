# Star Wars meme image roster

120 distinct public fan memes, visually reviewed on 2026-10-31. Original image bytes and watermarks are preserved. `roster.json` records the source post, uploader attribution (not a claim of original authorship), original URL, dimensions and SHA-256. These are third-party fan works, not official Star Wars images or bot-owned artwork.

The selection excludes explicit sexual content, slurs, political arguments, major plot reveals, unreadable tall strips and repeated images. Some jokes use familiar film scenes and cross-franchise references. Roster images are pinned to a Git commit when imported into D1; delivery caches Telegram file IDs. Disable an item with `UPDATE meme_roster SET active=0 WHERE id=...` to remove it from future sends, including queued retries.
